# لوحة الطالب - دليل الاستخدام

## نظرة عامة

تم إضافة لوحة خاصة للطلاب تحتوي على جميع المعلومات والخدمات التي يحتاجها الطالب.

## المميزات

### 1. تسجيل الدخول
- تسجيل دخول آمن للطلاب باستخدام البريد الإلكتروني وكلمة المرور
- نظام جلسات آمن
- كلمة المرور الافتراضية: `123456`

### 2. لوحة التحكم الرئيسية
- عرض المعدل العام
- نسبة الحضور الشهرية
- عدد المواد الدراسية
- عدد التبليغات الجديدة
- الجدول اليومي
- آخر التبليغات

### 3. الجداول الدراسية
- **الجدول اليومي**: عرض حصص يوم محدد
- **الجدول الأسبوعي**: عرض جميع الحصص للأسبوع في جدول منظم
- عرض معلومات المادة، المعلم، الوقت، والقاعة

### 4. الدرجات
- عرض جميع درجات الاختبارات
- فلترة حسب المادة
- حساب المعدل العام
- عرض النسبة المئوية لكل اختبار
- تلوين الدرجات حسب الأداء (أخضر/أزرق/أصفر/أحمر)

### 5. الحضور
- عرض سجل الحضور الشهري
- إحصائيات الحضور (نسبة الحضور، أيام الحضور، أيام الغياب)
- فلترة حسب الشهر
- عرض الحالة (حاضر/غائب) مع تلوين واضح

### 6. المواد الدراسية
- عرض جميع المواد الدراسية للطالب
- معلومات كل مادة:
  - عدد الساعات الأسبوعية
  - اسم المعلم
  - التخصص
  - المعدل في المادة
  - عدد الاختبارات
  - معلومات التواصل مع المعلم

### 7. التبليغات المدرسية
- عرض جميع التبليغات المدرسية
- فلترة حسب الأولوية (عاجلة/مهمة/عادية)
- عرض التبليغات العامة وتبليغات الصف
- عرض التاريخ والتفاصيل الكاملة

## بيانات تسجيل الدخول التجريبية

```
البريد الإلكتروني: ahmed@example.com
كلمة المرور: 123456
```

أو يمكنك استخدام أي بريد إلكتروني من بيانات الطلاب في قاعدة البيانات.

## المسارات

- `/student/login` - صفحة تسجيل الدخول
- `/student/dashboard` - لوحة التحكم الرئيسية
- `/student/timetable` - الجداول الدراسية
- `/student/grades` - الدرجات
- `/student/attendance` - الحضور
- `/student/subjects` - المواد الدراسية
- `/student/announcements` - التبليغات

## الأمان

- جميع صفحات الطلاب محمية بنظام مصادقة
- الجلسات تنتهي بعد 24 ساعة
- التحقق من صحة الجلسة في كل طلب

## ملاحظات

- تأكد من تحديث قاعدة البيانات بملف `api/database.sql` المحدث
- كلمات المرور مخزنة باستخدام MD5 (للبساطة - في الإنتاج استخدم password_hash)
- جميع البيانات مرتبطة بالطالب المسجل دخوله
