# نظام إدارة المدرسة

نظام إدارة مدرسة بسيط ومرتب باستخدام JavaScript و PHP و MySQL.

## المميزات

- ✅ لوحة تحكم رئيسية مع إحصائيات
- ✅ إدارة الطلاب (إضافة، تعديل، حذف، بحث)
- ✅ إدارة المعلمين (إضافة، تعديل، حذف، بحث)
- ✅ إدارة المواد الدراسية (إضافة، تعديل، حذف، بحث)
- ✅ واجهة مستخدم عصرية باستخدام Tailwind CSS
- ✅ دعم اللغة العربية بالكامل

## المتطلبات

- PHP 7.4+
- MySQL 5.7+
- WAMP Server
- متصفح حديث يدعم JavaScript ES6+

## التثبيت والإعداد

### 1. إعداد قاعدة البيانات

1. افتح phpMyAdmin في WAMP
2. قم بتشغيل ملف `api/database.sql` لإنشاء قاعدة البيانات والجداول
3. تأكد من أن اسم قاعدة البيانات هو `school_management`

### 2. إعداد Backend (PHP)

1. تأكد من أن WAMP يعمل
2. ضع مجلد `api` في مجلد `www` في WAMP (عادة `C:\wamp64\www\schoolMange\api`)
3. تحقق من إعدادات الاتصال في `api/config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_USER', 'root');
   define('DB_PASS', '');
   define('DB_NAME', 'school_management');
   ```

### 3. تشغيل التطبيق

1. تأكد من أن WAMP يعمل (Apache و MySQL)
2. افتح المتصفح على: `http://localhost/schoolMange/index.html`
3. لا حاجة لتثبيت أي حزم Node.js - التطبيق يعمل مباشرة!

## استخدام النظام

### الصفحة الرئيسية
- عرض إحصائيات عامة (عدد الطلاب، المعلمين، المواد)
- عرض نسبة الحضور اليوم
- عرض الطلاب الجدد

### إدارة الطلاب
- عرض قائمة جميع الطلاب
- إضافة طالب جديد
- تعديل بيانات طالب
- حذف طالب
- البحث عن طلاب

### إدارة المعلمين
- عرض قائمة جميع المعلمين
- إضافة معلم جديد
- تعديل بيانات معلم
- حذف معلم
- البحث عن معلمين

### إدارة المواد
- عرض قائمة جميع المواد
- إضافة مادة جديدة
- تعديل بيانات مادة
- حذف مادة
- ربط مادة بمعلم
- البحث عن مواد

## ملاحظات

- تأكد من أن WAMP يعمل قبل فتح التطبيق
- تأكد من أن قاعدة البيانات تم إنشاؤها بنجاح
- في حالة وجود مشاكل في الاتصال، تحقق من إعدادات `api/config.php`
- التطبيق يستخدم Tailwind CSS عبر CDN، لذا يحتاج اتصال بالإنترنت
